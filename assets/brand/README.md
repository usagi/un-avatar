# UN Avatar Brand Assets

| File | Role |
| --- | --- |
| `un-avatar-artwork-supervisor.png` | Main UNAvatar artwork for Supervisor Console, tray, app chrome, and profile fallback icons. |
| `un-avatar-artwork-renderer.png` | Renderer Process artwork. Use for Renderer executable/window identity, not for Supervisor chrome. |
| `../icons/un-avatar.ico` | Windows icon for UNAvatar app / Supervisor. |
| `../icons/un-avatar-renderer.ico` | Windows icon embedded in the Renderer Process executable. |

Keep artwork filenames lowercase kebab-case: `un-avatar-artwork-<role>.png`.
