# 更新・バックアップ・復元（Windows）

この手順は現行ソースの設定保存方式に対応します。公開済み旧版からの全組合せの移行確認を示すものではありません。

## 更新前に残すもの

1. Supervisorに保存中・未保存・保存失敗の表示があれば、保存するか不要な入力を破棄します。入力の保持はウィンドウ内だけなので、強制終了で片付けないでください。
2. 更新対象のRendererを停止し、Supervisorを終了します。複数個体や単独起動のRendererも確認します。
3. `%APPDATA%\UN Avatar\` を、アプリの設定フォルダー外へ丸ごとコピーします。`profiles`、`settings.toml`、`deleted_profiles`など、存在するファイルとフォルダーをまとめて残します。
4. プロファイルが参照する `.vrm`、`.unavatar`、画像などがこのフォルダーの外にある場合は、それらも別途残します。設定のコピーだけでは外部ファイルは複製されません。
5. 使用中の配布物一式も残します。EXEだけでなく、同梱DLLや関連ファイルを含めます。

`%APPDATA%` はエクスプローラーのアドレス欄へ入力できます。起動用スクリプトなどで保存先を変更している場合は、その実際の保存先と起動方法を記録してください。

## 新しい版へ更新する

新しい配布物を別フォルダーへ全て展開し、`un-avatar-supervisor.exe` を起動します。通常起動では既存の設定保存先を引き続き使います。配布物を別の場所に置くことは、設定を隔離した試用にはなりません。

編集中のプロファイル、モデルの場所、次回起動対象を確認してからRendererを起動してください。同じプロファイルの複数個体へ反映される設定もあるため、最初は対象を確認できる個体数で表示・モーション・出力を確かめます。外部アプリから自動起動する設定がある場合は、その参照先も確認します。

## 元の版へ戻す

1. 戻す設定を使っているSupervisorとRendererを全て終了します。
2. 更新後の設定と新しく編集した素材を、更新前のバックアップとは別に残します。
3. 設定フォルダーを更新前のコピーへ戻します。新旧ファイルを混ぜず、外部素材も必要に応じて対応する版へ戻します。
4. 元の配布物を元と同じ保存先で起動し、プロファイルとモデルを確認します。

新しい版で保存した設定を古いEXEだけで開く操作は、設定の復元ではありません。削除済みプロファイルの画面内復元も、アプリ全体の版を戻す手順とは別です。


### Rendererの停止が完了しない場合

停止要求を送ってもプロセスの終了を確認できない場合、その個体は「停止中」のまま管理に残る。停止ボタンから再試行できる。別に起動したRendererへ接続している場合も同じ扱いとなる。停止中はカメラ操作や撮影を行わず、終了確認後に「終了」へ移る。
